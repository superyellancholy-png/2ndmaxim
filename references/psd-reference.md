# 娄烨大师班 PSD 参考

来源：用户提供的《240919娄烨大师班-codex.psd》，1200 × 1600。这是同一暗房风格的局部文字放大示例，默认不沿用“忘了”的超大字号，不将其定义为独立必选版式。

## 图层实测

从下到上为原照片、#B54434 红色层（线性加深，100%）、纹理图片（实色混合，79/255）、黑色层（普通，150/255）、文字。文字颜色 #A8D8B9，正文与署名为又又意宋并开启仿粗体。

当前 render-poster.cjs 仍使用原有 multiply 与 soft-light 近似方案，不支持这里的线性加深、实色混合与额外黑色层。这些是源文件参考值，不是已经实现的渲染预设；精确复刻时需实现混合算法并使用原始纹理，不可只修改配置名称或承诺像素一致。
